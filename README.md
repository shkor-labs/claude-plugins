# Shkor Labs plugins for Claude Code

Turn what you vibe-coded into a product people pay for. → https://shkor.com/launch/

```
/plugin marketplace add shkor-labs/claude-plugins
/plugin install shkor-launch@shkor
```

Then, in your project: `/shkor-launch:launch`.

| Plugin | What it does |
|---|---|
| [shkor-launch](plugins/shkor-launch) | Seven-step launch playbook (offer → repo → public URL → payments → legal → first ads → numbers) with an MCP that does the infrastructure: static hosting on `<slug>.cil.by` from your repo, Stripe payment links under the studio's US entity, legal pages, Meta ads with bot-filtered stats, earnings. |

The playbook works without an account. The infrastructure needs a Shkor plan,
which you can get at https://shkor.com/start.
